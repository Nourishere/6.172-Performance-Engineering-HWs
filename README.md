# 6.172 Performance Engineering of Software Systems Homeworks

This repo contains my solutions and writeups for 6.172 performance engineering homeworks.

## Structure
Each HW has its own shape. Some HWs require text solutions only, which I might add as Markdown files or as annotated PDFs.

## Requirements
For parts that require code compilation, you might find the HW*.pdf and the Makefile useful for what you need to have installed. Also, most code that measures performance is run on AWS jobs machines using **awsrun**. I think if you understand your machine well, you wouldn't need that becasue performance is relative after all. 

## Status 
The repo is currently still in progress.
